# Nivra — Medicine Finder

Flask API + frontend for finding verified nearby medicine stock, salt-based brand suggestions, reservations, urgent requests, pharmacy owner listings, and admin verification.

## Run locally

```powershell
cd "C:\Users\grewa\Downloads\nivra-medicine-finder"
py -3 -m pip install -r requirements.txt
py -3 run.py
```

Open http://127.0.0.1:5000

- Admin desk: http://127.0.0.1:5000/admin  
- Owner desk: http://127.0.0.1:5000/owner  

If the page feels stuck from an old session, hard refresh (`Ctrl+F5`) or clear site data once. Use the nav **Motion** toggle only if you want the 3D/animations (off by default for smoother institute laptops).

## Host live (Render free)

1. Push this repo to GitHub.
2. Open [Render](https://render.com) → **New** → **Blueprint** (or Web Service) and connect the repo.
3. Render reads `render.yaml` / `Procfile` and starts:

   `gunicorn run:app --bind 0.0.0.0:$PORT`

4. Set env `NIVRA_SECRET_KEY` (auto-generated by blueprint) and keep `NIVRA_DEBUG=0`.
5. After deploy, open the `onrender.com` URL — full site + API works there.

SQLite resets when the free instance sleeps/redeploys; demo data is seeded automatically on first boot.

## Performance notes

- Heavy Lenis scroll removed
- 3D scene is lighter and paused off-screen
- Motion defaults **off** (turn on from nav if needed)
- OCR (Tesseract) loads only when scanning a prescription
